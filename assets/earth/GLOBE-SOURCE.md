# Globe land map

`ne_110m_land.geojson` is Natural Earth's 1:110 million land geometry, downloaded on 26 September 2026 from:

https://raw.githubusercontent.com/nvkelso/natural-earth-vector/master/geojson/ne_110m_land.geojson

Natural Earth data is public domain: https://www.naturalearthdata.com/about/terms-of-use/

The Vector Space page draws this generalised land map locally on a latitude/longitude globe. It is an overview, not street-level, imagery or navigation data. No map API key is required. Geographic coordinates use north-positive latitude and east-positive longitude in degrees. Earth is the only mapped body in this prototype; other planets need their own maps and coordinate conventions.
